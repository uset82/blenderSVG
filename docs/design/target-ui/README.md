# Target UI artboard sources

These files are a local copy of the private design canvas [blenderSVG Studio — Target UI](https://claude.ai/artifact/KF4tzS5uc1apNpW8YDygGN), made on 2026-09-23. They are the visual spec for Studio Phases 14–24 in [`../../PLAN_CHECKLIST.md`](../../PLAN_CHECKLIST.md).

Each `.dc.html` file is one artboard. It is static reference markup with inline styles, so read it for layout, spacing, colors, type, icons, copy and states. It is not production code: `{{accent}}` is a placeholder for the accent color, `./support.js` exists only inside the design canvas, and the example content (model names, prices, project names) is sample data.
