# Kurva brand and front page: artboard sources

These files are a local copy of the private design canvas [Kurva — Brand & Front Page](https://claude.ai/artifact/W58r7M5XaMbzEz4Zt2irnc), made on 2026-09-24. They are the visual spec for the Kurva tasks in [`../../brand/KURVA_TASK_PLAN.md`](../../brand/KURVA_TASK_PLAN.md).

| File | Artboard | Size |
|---|---|---|
| `Logo.dc.html` | Logo + tagline sheet: concepts, lockups, treatments, sizes, colors, type, rules | 1440 × 2300 |
| `Main.dc.html` | Landing page, desktop | 1440 × 5400 |
| `Mobile.dc.html` | Landing page, mobile | 390 × 2500 |
| `StudioHome.dc.html` | Studio Home restyled with Kurva tokens | 1440 × 900 |

Each file is a Design Component page. Its markup is plain HTML with inline styles and inline SVG. Read it as a spec. It runs only inside the canvas editor, because `support.js` is not in this folder.
